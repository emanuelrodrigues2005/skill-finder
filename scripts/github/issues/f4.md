# F4 — Pipeline CI/CD

<!--ISSUE:ci: workflow de CI com lint, três níveis de teste e gitleaks-->
## O que entrega

O `.github/workflows/ci.yml` sem AWS: `lint` (eslint + `tsc --noEmit`), `test-unit`,
`test-integration` (service container `postgres:16` com `healthcheck`), `test-api` e `secrets`
(`gitleaks`), publicando **apenas** JUnit XML e relatório de cobertura como artefatos.

## Critérios de aceitação

- [ ] workflow roda em `push` e em `pull_request`
- [ ] `test-integration` espera o Postgres por `healthcheck`, sem `sleep`
- [ ] artefatos com caminho explícito: JUnit XML + cobertura; **nunca** `tfstate`, `.env` ou `docker save`
- [ ] `secrets` reprova o PR ao achar segredo no diff
- [ ] nenhum job abre socket para fora (suíte offline verde no runner)

## Verificação

```bash
gh workflow list
gh run list --workflow=ci.yml --limit 5
gh run view <run-id> --log-failed     # vazio em execução verde
gh pr checks <pr>
```

## Dependências

- Depois dos testes em três níveis.

<!--ISSUE:ci: deploy automatizado com smoke e gate de testes provado-->
## O que entrega

O `.github/workflows/deploy.yml`: `preflight` (`aws sts get-caller-identity`), `build` com
`docker buildx` e push no ECR com tag = SHA, `tf-plan` só em PR, `deploy` por SSH com
`compose pull && up -d` + `prisma migrate deploy` lendo **apenas** `terraform output -json`, e
`smoke` que descobre a URL pelas saídas e **reprova o workflow** em qualquer desvio. Com
`workflow_dispatch`, `concurrency` e `permissions: contents: read`.

## Critérios de aceitação

- [ ] execução verde com os 7 jobs (`preflight, lint, test-unit, test-integration, build, deploy, smoke`)
- [ ] execução vermelha (teste quebrado de propósito, revertido) com `build` e `deploy` **`skipped`**, registrada em `docs/evidencias/f4-gate.md`
- [ ] imagem no ECR com tag = SHA implantado (sem `latest`)
- [ ] `smoke` reprova o workflow quando o banco é derrubado no host
- [ ] `$GITHUB_STEP_SUMMARY` com URL, digest e SHA; `gitleaks` verde; nenhum IP no repositório
- [ ] proteção do branch padrão exigindo `lint`, `test-unit`, `test-integration` e `secrets`

## Verificação

```bash
gh workflow run deploy.yml
gh run watch
gh run view <run-id> --log | grep -E '\*\*\*|skipped'
aws ecr describe-images --repository-name <repo> --query 'imageDetails[].imageTags'
grep -rnE '([0-9]{1,3}\.){3}[0-9]{1,3}' .github/ infra/ | grep -v '0\.0\.0\.0'   # vazio
git log --all --full-history -- "*.env"                                        # vazio
```
