# F2 — Aplicação

<!--ISSUE:chore(catalog): descobrir e congelar a fonte de dados do skills.sh-->
## O que entrega

Substitui "acesso não confirmado" por uma decisão **datada e medida** sobre como os dados das skills
são acessíveis, e congela uma **amostra real** (≥ 20 skills, sanitizada, com `sha256`) para que o
resto da F2 seja desenvolvido **sem internet**. `docs/app/amostras/` ainda não existe no repositório.

## Decisão (a primeira que fechar, na ordem)

| ID | Observação medida | Decisão |
| --- | --- | --- |
| **D1** | `Content-Type: application/json` + 200 sem JS + chaves idênticas em r1/r2 + ≥ 3 dos 5 campos | JSON público → cliente HTTP JSON |
| **D2** | HTML com payload em `__NEXT_DATA__`/`__NUXT__`/`ld+json` com ≥ 4 dos 5 campos | JSON embutido → extrair o payload |
| **D3** | Dados só no DOM e ≥ 4 dos 5 campos nas 3 páginas testadas | Scraping de DOM com seletor por campo |
| **D4** | ≥ 2 tentativas com 403/429/desafio, **ou** < 4 dos 5 campos, **ou** chaves divergentes | Bloqueado → *fixture-first*, sem código de rede |
| **D5** | 2 h de *timebox* sem fechar D1–D4 | Aplica **D4** por padrão, registrando "decisão por prazo" |

## Comando de descoberta

```bash
bash scripts/probe-skills-sh.sh                          # versão do repo

BASE=https://skills.sh                                    # equivalente manual
curl -sS -o docs/app/amostras/home.html -D docs/app/amostras/home.headers \
  -w 'http=%{http_code} type=%{content_type} bytes=%{size_download}\n' "$BASE/"
curl -sS "$BASE/robots.txt" -o docs/app/amostras/robots.txt -w '%{http_code}\n'
grep -o '__NEXT_DATA__\|__NUXT__\|application/ld+json' docs/app/amostras/home.html | sort | uniq -c
```

- [ ] `docs/app/amostras/skills-sample-YYYY-MM-DD.json` com ≥ 20 skills e, no mínimo, `id`, `name`, `url`, `stars`, `vulnerabilities`, `installs`, `summary`, `skill_md` (**ausente = `null`**)
