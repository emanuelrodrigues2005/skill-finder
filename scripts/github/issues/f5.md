# F5 — Observabilidade e segredos

<!--ISSUE:feat(observability): Prometheus, Loki, Grafana e 4 painéis-->
## O que entrega

Métrica, log e dashboard vivos no host: `observability/compose.obs.yaml` no profile `obs` com
Prometheus, Loki, Promtail, Grafana, Telegraf, cAdvisor e node-exporter (com `mem_limit` e retenção
de 7 dias), *scrape* de 15 s, log JSON com `request_id`/`route`/`status`/`latency_ms` redigido, e
**4 painéis** versionados com anotação de deploy por SHA.

## Critérios de aceitação

- [ ] `curl -s localhost:9090/api/v1/targets` sem alvo `down`
- [ ] `rate(http_requests_total[5m])` retorna série não vazia; p95 e 5xx aparecem
- [ ] LogQL `{service="api"} |= "error"` devolve linhas com `request_id`; erro provocado aparece no painel
- [ ] `observability/grafana/dashboards/main.json` com 4 painéis (RED, host, disponibilidade sintética, logs de erro) + provisioning versionado
- [ ] `/grafana/` devolve 401/302 sem credencial
- [ ] `docker stats --no-stream` abaixo dos `mem_limit`; `df -h` do volume < 80%

## Verificação

```bash
docker compose --profile obs up -d
curl -s localhost:9090/api/v1/targets | jq '[.data.activeTargets[] | select(.health!="up")] | length'   # 0
curl -s 'localhost:9090/api/v1/query?query=rate(http_requests_total[5m])' | jq '.data.result | length'
curl -s -o /dev/null -w '%{http_code}\n' http://<host>/grafana/   # 401 ou 302
docker stats --no-stream
```

## Dependências

- Depois do ciclo de apply/destroy. Pode rodar em paralelo com o deploy automatizado, validando local no profile `obs`.

## O que entrega

Nenhum segredo rastreável em repositório, log, imagem ou host: projeto/ambiente `prod` no Infisical
com `DB_PASSWORD`, `GRAFANA_PASSWORD`, **`LLM_API_KEY`** e `IP_HASH_SALT`, identidade de máquina com
escopo mínimo, `/opt/app/.env` gerado por `infisical export` com `chmod 600`, `::add-mask::` em cada
valor e nenhuma senha fixa no `user_data`.

> **Correção herdada:** a lista de `docs/04` F5-t8 (`DB_PASSWORD`, `JWT_SECRET`, `GRAFANA_PASSWORD`)
> está incompleta — o produto não tem JWT e precisa de **`LLM_API_KEY`** e `IP_HASH_SALT`.

## Critérios de aceitação

- [ ] `INFISICAL_TOKEN` gravado como Actions Secret; identidade de máquina com escopo mínimo
- [ ] `deploy` gera `/opt/app/.env` com `infisical export`, `chmod 600`, aplicando `::add-mask::` antes de usar
- [ ] `compose.yaml` sem valor fixo de senha; `user_data` sem senha
- [ ] `docs/seguranca.md` com modelo de segredos, rotação, escopo do token e riscos aceitos (`LabRole` larga, HTTP sem TLS, SSH exposto)
- [ ] remover o `.env` local, rodar o deploy e ver `/readyz` verde (o valor veio do cofre)
- [ ] `gitleaks detect` e `gitleaks detect --no-git` (imagem) verdes; `docker history` sem `ENV`/`ARG` de segredo
